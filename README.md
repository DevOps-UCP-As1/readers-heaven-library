# Readers Haven Library

A responsive multi-page library website developed as a team project.

## Technologies

- HTML5
- CSS3
- JavaScript
- Parcel
- Git and GitHub
- Docker
- Nginx

## Project Structure

- src/ - Website pages and source files
- styles/ - Shared CSS styles
- dist/ - Production build output

## Development

Install dependencies:

npm ci

Build the website:

npm run build

## Docker

Build the Docker image:

docker image build -t readers-haven-library .

Run the container:

docker container run -d -p 8080:80 readers-haven-library

Open http://localhost:8080
